# SMK-37 recipe 1: DX747's SMK-37 controls layer (targets/smk37/app/smk37_controls.c) on the events the board's scanner reports:
# keys with velocity, faders and the fader bank, pads as scenes and as mute and solo, the pedal, safe boot.
# Printed buttons by the board's ids: 1 FADER BANK, 12 PATCH (Parts), 17 SEQ REC (save a scene), 15 SEQ (Mix), 13 PARA (edit pages) (button_map in smk37_controls.c).
boot
wipe
run 400
# the master level (encoder 8) starts at 100 of 127: full, so that the peaks compare with FM-1 recipe 9
senc 7 27
# keys: the velocity they are struck with reaches the engine (soft 10, firm 80: the thresholds of FM-1 recipe 9); key 12 is middle C
skey 12 10
run 60
expect_voices 1
expect_below 300 0.16
skey 12 0
run 100
expect_voices 0
skey 12 80
expect_peak 300 0.19
skey 12 0
run 100
expect_voices 0
# a key held while the octave changes lets go of the note it started
skey 12 90
run 60
expect_voices 1
sbtn 5 1
sbtn 5 0
skey 12 0
run 100
expect_voices 0
# faders: part levels, on the screens where they are levels (Mix here; on Parts they are the filter). The first reading of a fader, at power-on, only says
# where it stands; after that a fader sets its part's level as soon as it moves, wherever it was left
sbtn 15 1
sbtn 15 0
run 100
expect_screen 8
expect_level 0 127
sfader 0 127
expect_level 0 127
sfader 0 64
expect_level 0 64
sfader 0 126
expect_level 0 126
sfader 0 40
expect_level 0 40
# FADER BANK: faders 1 to 4 become parts 5 to 8, and set them as soon as they move, from wherever they were left; part 1 keeps its level
sbtn 1 1
sbtn 1 0
expect_lamp 1 1
sfader 0 100
expect_level 4 100
expect_level 0 40
sfader 0 50
expect_level 4 50
expect_level 0 40
sbtn 1 1
sbtn 1 0
expect_lamp 1 0
# fader 2 was never touched: its first reading only says where it stands, then it moves part 2
sfader 1 127
expect_level 1 127
sfader 1 20
expect_level 1 20
# a fader that was moved on another screen is not dead on this one (Parts: the filter, here part levels again)
sbtn 12 1
sbtn 12 0
run 100
expect_screen 1
sfader 1 90
sbtn 15 1
sbtn 15 0
run 100
expect_screen 8
sfader 1 60
expect_level 1 60
sbtn 1 1
sbtn 1 0
sfader 1 30
expect_level 5 30
sbtn 1 1
sbtn 1 0
# pads: scene recall on the Scenes screen. Save the setup as scene 1, change a level, recall it with pad 1
sbtn 12 1
sbtn 12 0
sbtn 17 1
sbtn 17 0
run 100
expect_screen 11
sbtn 17 1
sbtn 17 0
run 300
sfader 0 20
expect_level 0 20
spad 0 1
spad 0 0
run 300
expect_level 0 40
# the mixer: the top row of pads mutes part 1 to 8, the lower row soloes them, always (no key to press first); dim red until muted, then bright red
sbtn 15 1
sbtn 15 0
run 100
expect_screen 8
expect_pad_color 0 300808
expect_pad_color 8 302000
spad 0 1
spad 0 0
run 100
expect_pad_color 0 ff2020
skey 12 90
run 100
expect_voices 0
skey 12 0
spad 0 1
spad 0 0
run 100
skey 12 90
run 100
expect_voices 1
skey 12 0
run 100
# the pedal and the wheels must not disturb anything
spedal 127
sfader 4 100
sfader 5 90
spedal 0
run 100
# safe boot: SCALE and CHORD (add layer and remove layer) held at power-on
boot safe
expect_screen 13
